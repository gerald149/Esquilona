# Gerald Esquilona — Personal Portfolio

## Run the website
1. Extract this folder.
2. Open `gerald-portfolio-fixed` in Visual Studio Code.
3. Open `index.html`.
4. Right-click and choose **Open with Live Server**.

## Folder structure
- `index.html` — Home
- `about.html` — About
- `gallery.html` — Gallery
- `css/style.css` — Website design
- `images/` — Temporary SVG image placeholders

The SVG images are placeholders so the layout displays immediately. Replace them with your own images if you want, and update the image filenames in the HTML accordingly.
